# 📖 About

This repository contains my complete Node.js learning journey covering backend development with Node.js and Express.js.

The repository includes backend fundamentals, HTTP servers, asynchronous programming, MVC architecture, template engines, databases, authentication, REST APIs, file handling, and real-world backend concepts with organized code and notes.

---

# 🎯 Objectives

- Build a strong backend foundation
- Understand Node.js architecture
- Work with HTTP requests and responses
- Learn asynchronous programming
- Build applications using Express.js
- Understand MVC Architecture
- Work with SQL and MongoDB
- Learn Mongoose
- Implement Authentication & Authorization
- Build REST APIs
- Handle File Uploads
- Write clean and maintainable backend code
